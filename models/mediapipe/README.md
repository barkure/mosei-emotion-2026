# MediaPipe Face Landmarker

Place `face_landmarker.task` directly in this directory.

Resource: MediaPipe Face Landmarker, version `float16/1`. Run `pixi run resources` from the project root to download and verify the pinned file.

The model occupies approximately 3.76 MB and is excluded from Git. It is used to extract Q1 facial features from the original videos; Q2/Q3 use the supplied visual feature arrays instead.
