# 问题一：三模态特征提取与词时间戳驱动的时序对齐

正式结果入口：`outputs/q1_features/q1_final/`。100份自包含NPZ位于其 `features/` 目录。

## 方法主线

方法简称：基于词时间戳与区间交叠的三模态时序对齐。

原视频检查 → 共同媒体时间轴 → 官方文本和原生音视频特征 → 具有证据的词时间 → 按区间交叠聚合 → 来源与质量记录。
每条样本以全部官方词构成共同序列，保留实际长度。

## 时间与采用规则

- 冻结声学模型 `facebook/wav2vec2-base-960h`，revision `22aad52d435eb6dbaf354bdad9b0da84ce7d6156`；16 kHz，输出步长20 ms。
- 官方文本不改。数字采用单独的英语读法映射并保留备选；词与原文字符、BERT子词索引保持对应。纯标点位置保留但不赋予发音时间。
- CTC Viterbi返回每个字符的首个与最后一个发射帧；词终点使用末字符的结束帧。
- 完整内容确认样本按官方序列对齐；部分一致样本仅对用户明确确认的短语定位，使用自由解码字符时间辅助定位后局部强制对齐。
- 每词另取前后各3词上下文、边界外各160 ms重新检查路径。全段/短语与局部字符平均置信度均≥0.5，两边界最大差≤100 ms。
- 全落入检测静音、时间越界或重叠的词不采用；跨度超过max(1秒,0.2×规范化字母数秒)的词标记跨度异常。
- 阈值是固定的工程采用规则，未用情感标签调参。局部与全局路径使用同一声学模型，不能当作独立准确性验证。
- 时间为CTC音频局部秒数加音频解码首帧时间；16 kHz重采样绝对延迟未标定。20 ms步长不作为边界精度结论。

## 特征与聚合

文本：冻结BERT-base-uncased，原生子词768维；一个官方词的内容子词取平均。修订号、权重哈希见预训练资源清单。
语音：16 kHz、25 ms窗/10 ms步长，13 MFCC、log RMS、F0、谱质心、过零率共17维。
按原生窗与词区间交叠长度加权，F0仅在可测窗重新归一化。F0采用自相关法，搜索范围60–400 Hz。
视频：原视频全部显示帧，宽640，MediaPipe Face Landmarker VIDEO模式，每个片段按PTS一次连续推理，最多返回2张脸。
保留52维系数和检出数量；检出多张脸时不确定说话人身份，故不用于词级平均。单人脸可用也不代表已独立验证说话人身份。

视频显示区间使用[PTS, PTS+正帧持续时间)，终点不超过下一PTS；缺少有效时长时采用下一PTS，最后一帧采用解码覆盖终点。
按显示区间与词区间的交叠长度对可用面部帧加权，因此已经开始显示的画面也可覆盖短词。
所有词区间直接从原生特征聚合；没有词时间时仍保留原始文本、音频、视频序列。

## 词时间筛选的作用与数量

1932个官方位置中，20条异常样本包含296个；80条样本包含1636个，其中1533个词时间可用，103个不可用。局部原因为低置信82、确认短语范围外10、静音区间6、无目标字符4、跨度异常1。该筛选避免这些候选时间参与词级聚合，所有原文与原生特征保留。没有独立人工边界真值，不能据此量化时间准确率的提升。对应论文图4.3；覆盖分布与典型样本分别见图4.4、4.5。

论文按`ctc_path`给出CTC合法前驱、最大路径递推、初始化、回溯及重复字符限制。聚合性质给出在原生特征与有效性固定时、归一化权重变化引起的表示差上界及推导；该界不代表实测时间误差或精度。
